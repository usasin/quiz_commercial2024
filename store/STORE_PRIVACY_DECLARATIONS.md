# Store privacy declarations - release 1.0

## Google Play Data safety
For the current source code in this release:
- Data collected: No.
- Data shared with third parties: No.
- Account creation: No.
- Ads: No.
- Analytics SDK: No.
- User-selected ZIP files are processed locally for import/analysis/export.

## Apple App Privacy
For the current source code in this release:
- Data Used to Track You: None.
- Data Linked to You: None.
- Data Not Linked to You: None.
- The app does not intentionally transmit imported source code or prompts to a remote server in release 1.0.

IMPORTANT: Re-check these answers if analytics, advertising, login, payments, cloud storage, remote AI, crash reporting, or any server-side feature is added.
