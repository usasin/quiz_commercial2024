# App Store listing - EN

Name: App Creator AI
Subtitle: Create and prepare Flutter apps

Description:
App Creator AI helps you start a Flutter project from an idea or inspect an existing project supplied as a ZIP file.

Describe your application, choose Android and/or iOS, review the suggested screens and features, then export a structured Flutter starter project. For an existing project, App Creator AI analyzes the ZIP and prepares a working copy with your requested modification brief.

Main features:
- Guided project creation from an idea
- ZIP import and analysis
- Flutter, Android, iOS, Firebase and Codemagic detection
- Flutter ZIP export
- Codemagic build preparation

Suggested category: Developer Tools / Utilities
