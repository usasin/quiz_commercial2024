# EmploiBoost 2.3.0 — build 65

## Nouveau diplôme : Négociateur technico-commercial

- parcours officiel **RNCP39063 — niveau 5** ;
- 3 chapitres : CCP1, CCP2 et certification ;
- 12 modules progressifs ;
- 36 leçons originales orientées décision et mise en pratique ;
- 180 questions contextualisées réparties sur trois niveaux ;
- 36 simulations professionnelles guidées ;
- 6 sujets d’examen complets issus de secteurs B2B différents ;
- 18 fiches pratiques : scripts, PAC, découverte, proposition, négociation
  et certification ;
- migration Firestore déterministe de 335 écritures.

## Examen blanc NTC

- un même cas suit le candidat du tableau de bord jusqu’au jury ;
- analyse chiffrée, plan d’actions et proposition technique et commerciale ;
- appel de prospection avec personnage IA ;
- négociation longue avec objections et contreparties ;
- analyse SWOT et décision commerciale ;
- questions du jury et bilan croisé des productions ;
- mode guidé mobile et mode avec les principales durées officielles ;
- accès Premium vérifié avant tout appel IA.

## Architecture multi-diplôme

- Assistant pédagogique isolé par parcours : aucun mélange CIP/NTC ;
- chargement direct des contenus du diplôme sélectionné ;
- suggestions et identité du coach configurables dans `tracks/{trackId}` ;
- prompts IA adaptés automatiquement à RNCP37274 ou RNCP39063 ;
- écrits, feedback oral et critères de jury transmis avec le bon contexte ;
- ancien script CIP protégé pour ne jamais réétiqueter le parcours NTC ;
- identité EmploiBoost et progression rendues génériques pour les futurs
  diplômes.

## Positionnement

Le parcours réunit dans une seule application les éléments généralement
séparés : micro-apprentissage, quiz contextualisés, outils terrain, jeu de rôle
vocal IA, correction des productions, examen blanc, XP, badges et défis.

Le contenu est un support de préparation fondé sur le référentiel public. Il ne
remplace pas l’organisme certificateur ni les consignes données au candidat le
jour de sa session.
