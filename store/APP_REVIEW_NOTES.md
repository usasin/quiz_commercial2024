# App review notes - release 1.0

App Creator AI is a local utility for creating Flutter starter projects and inspecting existing Flutter ZIP archives. No login is required. There are no purchases, ads, analytics SDKs or remote AI calls in this release.

Suggested reviewer flow:
1. Open the app.
2. Tap “Préparer une nouvelle app”.
3. Enter an app name and a short description.
4. Choose Android and/or iOS and generate the project plan.
5. Export the generated Flutter ZIP using the system share sheet.
6. Alternatively, use “Analyser un ZIP existant” to select a Flutter ZIP and review the local analysis.

The imported file is processed locally on device. Release 1.0 prepares starter code, blueprints and modification briefs; it does not claim to automatically rewrite an entire imported codebase.
