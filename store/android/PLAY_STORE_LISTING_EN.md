# Google Play listing - EN

App name: App Creator AI

Short description:
Create Flutter app projects from an idea or inspect an existing Flutter ZIP.

Full description:
App Creator AI helps you turn an idea into a structured Flutter project. Describe the app you want to create, choose the target platforms, review suggested screens and features, then export a Flutter project as a ZIP file.

You can also import an existing Flutter ZIP. App Creator AI inspects its structure, detects Flutter, Android, iOS, Firebase, Codemagic and common packages, then prepares a working copy containing your requested changes for the next development step.

Main features:
- Guided Flutter project creation
- Existing ZIP project import
- Flutter structure analysis
- Android, iOS, Firebase and Codemagic detection
- ZIP project export
- Android/iOS build preparation for Codemagic

Suggested category: Tools
